# App icon

`AppIcon.png` is the selected Tracker Trapper artwork: a green checkmark bird with dot eyes and a blunt tail inside a gold cage, with bars in front and behind. Created with built-in ImageGen and selected by the user on September 18, 2026.

`scripts/package-app.sh` preserves transparency while generating the standard 16–1024 pixel macOS icon representations, compiles `AppIcon.icns`, and sets the bundle's `CFBundleIconFile` entry. The monochrome menu-bar status symbol remains independent of the application icon.
