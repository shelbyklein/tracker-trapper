# Tracker Trapper

A planned macOS menu-bar companion for GitHub-issue-linked development checklists and live agent progress.

See the [implementation plan](instructions/2026-09-17-menu-bar-progress-tracker.md) for architecture, stable todo IDs, acceptance checks, and progress reporting rules.

Track implementation in [issue #1](https://github.com/shelbyklein/tracker-trapper/issues/1). Its checkboxes are the authoritative progress record.

Status: planning only. No application is implemented yet.
